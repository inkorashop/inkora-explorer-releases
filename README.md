# INKORA Explorador de archivos

Aplicación de escritorio para navegar archivos y carpetas reales de Windows.

- **Descarga estable:** [Instalador para Windows x64](https://github.com/inkorashop/inkora-explorer-releases/releases/latest/download/INKORA-Explorador-de-archivos-Setup.exe)
- **Releases y notas:** [Versiones publicadas](https://github.com/inkorashop/inkora-explorer-releases/releases)
- **Fuentes:** repositorio privado `inkorashop/inkora-explorer`.

Se instala para el usuario actual, no requiere permisos de administrador y usa los permisos ya configurados en Windows. No incluye una firma Authenticode, por lo que Windows puede advertir que el editor no está reconocido.
